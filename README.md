# Focus Mode Fullscreen Chrome Extension

A lightweight Chrome extension that enables a clean full-screen focus mode on any page and allows tab switching via custom shortcuts.

## Features
- Toggle fullscreen focus mode (`Cmd+Shift+F` on Mac / `Ctrl+Shift+F` on Windows)
- Cycle tabs left/right (`Cmd+Shift+Left/Right` on Mac / `Ctrl+Shift+Left/Right` on Windows)
- Works on YouTube and all websites

## How to Install
1. Clone or download this repository as a `.zip` file and extract it.
2. Open Google Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the extracted folder.
